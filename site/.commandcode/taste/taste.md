# Taste

## Frontend / UI
- Prefers Space Mono as the code/monospace font. Confidence: 0.9
- Wants code blocks to include a copy button (with hover-reveal and "Copied" feedback state). Confidence: 0.9
- Prefers rendering prose content with a proper markdown renderer (e.g., `marked`) that outputs semantic HTML, rather than injecting raw HTML via `set:html`. Confidence: 0.8

## Tooling / Workflow
